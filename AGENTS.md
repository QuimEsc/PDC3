# Continuïtat obligatòria

- Abans de qualsevol intervenció, llig `HANDOFF.md` i el checkpoint actual del principi de `PDC3_HANDOFF.md`. No repetisques l'històric complet sense necessitat.
- En acabar una modificació, prova o investigació, actualitza `HANDOFF.md` amb estat, data, fitxers, motius, proves executades i resultat, limitacions, pendents i pròxima acció. Fes-ho també quan no es resolga el problema.
- Mantín el checkpoint actual de `PDC3_HANDOFF.md` coherent amb este handoff; conserva l'històric.
- Diferencia API real, simulacions i comprovacions no executades. No declares producció reparada amb un fix només local. No desplegues sense autorització explícita.
- Cap clau, token, contrasenya, resposta identificable o dada acadèmica privada en codi, logs, captures, commits o handoffs. Les configuracions versionades són plantilles; les credencials continuen fora del repositori.
- No imprimisques diffs històrics de configuracions que puguen contindre secrets. No reescrigues història ni regeneres credencials sense instrucció.
- No qualifiques ni modifiques dades reals per provar una integració. Les proves d'API han d'usar dades fictícies i consum limitat.
